# Music Note Guesser

Music Note Guesser is an interactive web-based educational tool designed to help musicians and students practice musical sight-reading and note identification. The application randomly displays musical notes on a staff and provides immediate feedback on user guesses.

## Features

- Interactive sheet music rendering for practice.
- Treble and bass clef options.
- Real-time input validation and visual feedback.
- Customizable difficulty levels and note ranges.
- Clean, responsive user interface designed for both desktop and mobile devices.

## Tech Stack

- **HTML5** - Page structure and semantic layout.
- **CSS3** - Responsive design and modern styling.
- **JavaScript (ES6+)** - Core game logic, note generation, and score tracking.
